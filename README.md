# Sample App

A minimal yet evolving **Kotlin Android app** designed to experiment with automation workflows and to **showcase custom UI components** from the [**r-components**](https://github.com/revanthkumarJ/r-components) library.  

---

## 🎯 Purpose
This repository serves as a **playground** to explore:

- ⚙️ **GitHub Actions** – setting up CI/CD pipelines for Android  
- 📲 **Firebase App Distribution** – managing and distributing builds for testing  
- 🧩 **UI Component Demos** – visual previews and examples of reusable components from `r-components`

---

## 📱 App Overview
- 🏠 **Home Screen** – Displays a list of buttons, each representing a UI component.  
  - Tapping a button navigates to that component’s preview screen.  
  - Each button’s label matches the **component name** (e.g., `RevButton`, `RevOutlinedTextField`, etc.).  
  - After adding the `r-components` library to your project, you can directly use these showcased components in your own app.  

---

## 📌 Features
- ✅ Multiple screens demonstrating all components from the `r-components` library  
- ✅ Easy navigation between component previews  
- ✅ Originally a single-screen demo; now expanded into a full component showcase  
- ✅ Lightweight and ideal for automation experiments  
- ✅ Integrated with **Firebase App Distribution** and **GitHub Actions**

---

## 🧱 Components Showcased
Some of the components you can preview and use in your projects:

- `RevButton` / `RevOutlinedButton` / `RevTextButton`
- `RevOutlinedTextField` / `RevPasswordField`
- `LoginPage`
- Any other custom composables included in `r-components`
